# Manually downloaded spreadsheets

Some .gov.au sites refuse requests from GitHub's cloud runners. If a source shows
"failed" on the site's Data & methods tab, download its spreadsheets in a browser
and commit them here. The next build parses them like downloaded files.

| Folder | What to put in it | Where to get it |
|---|---|---|
| `nhmrc/` | Outcomes / summary of results / grants data `.xlsx` | https://www.nhmrc.gov.au/funding/data-research/outcomes |
| `mrff/` | MRFF grant recipients `.xlsx` | https://www.health.gov.au/resources/publications/medical-research-future-fund-mrff-grant-recipients |
| `rbg/` | Research Block Grant allocations (time series) `.xlsx` | https://www.education.gov.au/node/17511 |
| `herdc/` | Research income time series `.xlsx` | https://www.education.gov.au/node/3974 |
